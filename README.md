# Geist 使用指南

**从零开始，只要会打开网页就能用。** 不需要懂 AI，不需要懂代码。

---

## 一、Geist 是什么？

Geist 是一个温和、愿意倾听的 **AI 陪伴助手**，不是心理咨询师或医生。

它和普通 AI 最大的不同：**它不急着给你答案，它先听你说。** 它会试着接住你的情绪，陪你慢慢整理自己的想法。

> 它的理念写在开场里：
> *先听你说。这里不急。*

【重要提醒】它是 AI，不是医生。它能陪伴、能倾听，但不能替代真正的心理咨询或医院。如果你处于危险或紧急的情绪中，请直接拨打 **全国心理援助热线 12356**。

## 二、最快上手：30 秒开始聊天

### 方式 A：拿到网站文件（最常见）

1. 打开公开网址，或在本机运行 `node server.js` 后访问 `http://127.0.0.1:8788`。
2. 也可以双击 `Geist.html` 体验界面；`file://` 页面不能使用安全代理连接个人 API。
3. 你会看到一张海报一样的欢迎页，大字写着「先听你说。」。右上角可以切换 Geist 的两种模式：
   - **分析师**：暖黄色，以倾听和陪伴为主（开场是歌德《浮士德》的名句，页脚有尼采「骆驼·狮子·小孩」三个小记号）；
   - **哲学家**：克莱因蓝，像一位陪你深夜想问题的人，主题是「上帝已死」（页角有一枚淡淡的头盖骨）。
4. **鼠标在页面任意位置点一下**，等两三秒，Geist 会先开口问你第一个问题。
5. 在最底下的输入框里打字，按 **回车键**（Enter）发送，像聊微信一样。

### 方式 B：点开公开网址（最简单）

直接打开 **geistd.github.io/geist**（推荐，手机上收藏一下就行），其余步骤和上面第 3 步开始完全一样。

> 小知识：页面托管在 [GitHub Pages](https://pages.github.com)，模型请求经 Geist 的 CloudBase 代理发送。你也可以在「偏好」中填写自己的 key；使用免费公共线路前会明确征求同意。

### 小提示

- 回复可能需要等几秒到几十秒，看到三个小点跳动就是它正在"想"，耐心等一下。
- 没话说很正常，你可以发「不知道说什么」，它也会接得住。
- 聊天记录保存在当前浏览器；为生成回复，当前对话和必要上下文会发送给你选择的模型服务。请勿输入不愿交给模型服务处理的敏感信息。

## 三、进阶（可选）：让它更"聪明"一点

接入模型需要服务商的 API key。服务商可能收费或设有额度限制，请先查看服务商当前的价格和隐私政策。

填写你自己的 API key 后，消息会经 Geist 代理转发至所选服务。

### 大白话解释

"钥匙"叫 **API Key**（念作 A-P-I key）。它相当于调用 AI 服务的凭证，应像密码一样保管；调用费用和免费额度由服务商决定。

### 步骤（跟着做就行）

1. 用浏览器打开 [open.bigmodel.cn](https://open.bigmodel.cn)（智谱，一家国内的 AI 公司）。
2. 点右上角「注册 / 登录」，用**手机号 + 短信验证码**注册（可能还要身份证实名，按页面提示来就可以，都免费）。
3. 注册登录进去后，找到左侧的 **「API Keys」**，点「创建」，会生成一串字母数字混合的密钥，**点复制**。
4. 回到 Geist 网页。第一次打开聊天后，它会弹出一张卡片，标题是 **「接一个你常用的模型」**：
   - 下拉框选 **「智谱 GLM-4-Flash（免费）」**（地址和模型名会自动填好）；
   - 把刚才复制的密钥粘贴进 **「API Key」** 那一栏；
   - 点 **「保存并开始」**。
5. key 只保存在当前浏览器会话中；关闭浏览器后需重新填写。你也可以稍后在「偏好」中更换服务。

> 没看到卡片？点网页右上角的 **「偏好」**，里面填同样的三样东西，点「保存」。

### 想换其他公司的模型？

目前支持智谱、DeepSeek、OpenAI 和通义千问的 OpenAI 兼容接口。Claude 原生接口协议不同，暂不作为直接预设提供。各服务的价格、可用模型和数据处理方式请以服务商说明为准。

## 四、本机运行（个人使用）

1. 安装 [Node.js](https://nodejs.org/)。
2. 可在项目目录创建被 `.gitignore` 忽略的 `key.txt`，写入服务商 key；也可使用环境变量 `GEIST_API_KEY`。
3. 在 PowerShell 进入项目目录并运行：

   ```powershell
   node server.js
   ```

4. 打开 `http://127.0.0.1:8788`。本机代理只监听回环地址，不向局域网或公网开放。

**不要用公网隧道暴露 `server.js`。** 若要公开部署，请使用 Vercel/CloudBase，并在平台配置调用额度、WAF/限流或身份验证。浏览器 CORS 白名单不是身份验证；云函数的进程内限流也不能替代平台级限额。

## 五、架一个「国内免 VPN」的公开网址（CloudBase 部署）

### 这是给谁看的

给站长（你）。目的是做一个**放在国内**的公开网址；聊天经 CloudBase 云函数转发到模型服务。

部署完成后会有两个版本：

| 版本 | 地址 | 适合谁 |
| --- | --- | --- |
| 海外版（Vercel） | geist-pied.vercel.app | 在国外/能上外网的人 |
| **国内直连版（CloudBase）** | 形如 `xxx.tcloudbaseapp.com` | **在国内、不想折腾 VPN 的人** |

两版代码同一套，只是后端线路不同。

### Vercel 线路

部署后，个人 key 可经同源 `/api/chat` 代理使用。若要启用项目共享线路，在 Vercel 项目环境变量中设置 `GEIST_API_KEY` 和 `GEIST_ENABLE_SHARED_KEY=true`；只有在已配置平台级认证/限额后才开启。使用自定义域名时，将完整来源加入 `GEIST_ALLOWED_ORIGINS`。

### 原理（一句话）

腾讯云开发是腾讯家的"网站+后台"托管服务：**静态托管**放网页文件，**云函数**作为安全代理转发聊天请求。费用和额度以腾讯云控制台当前说明为准。

### 准备

1. 访问 [cloud.tencent.com](https://cloud.tencent.com)，用微信扫码注册/登录（个人实名即可）。
2. 打开产品 **「云开发 CloudBase」**（控制台里搜"云开发"），按提示开通（按量计费，无最低消费）。

### 第一步：创建环境

1. 在云开发控制台点 **「新建环境」**，随便取个名（比如 `geist`），地域选离你近的。
2. 创建完成后，在环境卡片上找到一串 **「环境ID」**（类似 `geist-3g2xxxxxxx`），**记下来**，后面要用两次。

### 第二步：创建两个云函数

在控制台左侧选 **「云函数」**，点 **「新建云函数」**，一共建两个：

**① 函数名 `health`**（健康检查，前端靠它探测线路）

- 运行环境选 **Node.js 16+**；
- 直接把仓库里 `cloudbase/health/index.js` 的**全部内容**粘进在线编辑器的 `index.js`，点保存。

**② 函数名 `chat`**（真正的转发员）

- 运行环境同上，粘贴 `cloudbase/chat/index.js` 的全部内容；
- **超时时间改成 60 秒**；
- 若要使用项目共享线路，在这个函数的 **「编辑 → 环境变量」** 里新增变量：
  - 变量名：`GEIST_API_KEY`
  - 变量值：你的智谱密钥（就是第三节那串字母数字）
  - 变量名：`GEIST_ENABLE_SHARED_KEY`
  - 变量值：`true`

> 默认不启用共享 key。只有配置了云平台级身份验证、全局限额/WAF 后才设 `GEIST_ENABLE_SHARED_KEY=true`；否则访客应填写自己的 key。用户自带的 key 经 HTTPS 临时转发，应用代码不会写入日志或文件。

### 第三步：开通 HTTP 访问服务

云开发控制台左侧找 **「HTTP 访问服务」**（如果找不到，去 chat 函数的 **「触发管理」** 里建**「API 网关触发」**，用网关给的地址代替下面说的域名，原理一样）。

- 新建两条路径，都绑定到你的环境：
  - 路径 `/health` → 函数 `health`
  - 路径 `/chat` → 函数 `chat`
- 记下默认访问域名，形如 `https://<环境ID>.service.tcloudbase.com`。

**验收**：用浏览器直接打开 `https://<环境ID>.service.tcloudbase.com/health`，能看到 `{"ok":true,...}` 说明健康检查可用；`keyConfigured` 只表示共享线路的服务端 key 是否配置，不能单独证明 `/chat` 可用。

### 第四步：上传网页

1. 控制台左侧选 **「静态网站托管」**（第一次用需要点开通，选你刚建的环境）。
2. 把仓库里的 `Geist.html` **上传**到根目录（覆盖默认的 index.html 没关系，也可以把旧 index.html 删掉）。
3. 记下静态站点的默认域名（形如 `xxx-xxxx.tcloudbaseapp.com`）。

### 第五步：把「环境ID」填回网页文件（重要）

网页内已配置当前 CloudBase 环境 ID。若换了环境，改 `Geist.html` 中的 `CB_ENV_ID` 后重新上传；GitHub Pages 会使用该 CloudBase 代理。

1. 打开 `Geist.html`，搜索 `CB_ENV_ID`，找到这行：

   ```js
   const CB_ENV_ID = '当前环境ID';
   ```

2. 将其替换为你自己的环境 ID：

   ```js
   const CB_ENV_ID = 'geist-3g2xxxxxxx';
   ```

3. 保存，**重新上传覆盖**静态托管里的文件。刷新网页，就能聊了。

> 页面会限制允许的 CORS 来源。若使用自定义域名，请在 CloudBase 函数配置 `GEIST_ALLOWED_ORIGINS`，以逗号分隔列出完整的 `https://` 来源。

**公开前的安全事项：** CORS 白名单不等于身份验证。若启用共享 key，公开 `/chat` 仍可能被自动化脚本滥用；部署前应在云平台配置全局限额、WAF/验证码或身份验证。代码中的进程内限流只是基础保护。

### 不用的时候

按量计费的环境在控制台可以**直接删除**，不产生费用。免费额度内个人使用通常不花钱；具体额度以腾讯云控制台页面为准。

## 六、常见问题（FAQ）

**Q：它怎么那么久不回话？**
模型服务可能较慢或暂时不可用。失败时 Geist 会保留未发送消息，显示提示，供你检查设置后重试。

**Q：我们的聊天会被别人看到吗？**
聊天记录和连续性笔记保存在当前浏览器；生成回复时，相关对话会发送给所选模型服务处理。服务商可能按其政策记录请求。免费公共线路会把对话发送给第三方服务。请勿输入不愿分享的敏感信息；可在「重新开始」中清除本机对话。

**Q：它到底是人还是机器人？**
是 AI。它有时真的很像真人，但它是程序，不是真人。

**Q：怎么切换分析师和哲学家？**
右上角有两个小按钮「分析师」「哲学家」，点哪个就换哪个（欢迎页和聊天页都能切）。两种模式的聊天记录各自保存，互不干扰，切换也会记住。哲学家模式下如果聊到生死、意义这类话题，它会陪你想得更深。

**Q：克莱因蓝为什么要配一只头盖骨？**
Geist 在德语里是"精神、鬼魂"的意思。头盖骨是它的记号——死亡气质的克莱因蓝里，藏着 Geist 的幽灵。觉得吓人的话，切到黄色的分析师模式就好。

**Q：我心情真的很差，它能救我吗？**
Geist 是 AI 陪伴工具，**不能替代医生或心理咨询师**。请联系信任的人或专业人士；在中国可拨打 **12356**（全国心理援助热线）。若有立即人身危险，请联系当地急救或报警服务。

**Q：换了一台电脑，怎么做？**
把 `Geist.html` 文件拷过去（或重新打开网址）就行。想接"钥匙"就在那台电脑上重新填一次。

## 七、技术说明（给开发者）

- 单文件前端：`Geist.html`，无需前端构建工具；个人 API key 需通过 HTTPS 网站或本机代理发送。
- 模型请求线路：个人 key → 项目代理（本机 / Vercel / CloudBase）→（仅在用户明确同意后）免费公共线路。支持智谱、DeepSeek、OpenAI、通义千问的 OpenAI 兼容接口。
- 对话连续性笔记会保存在本机，并随上下文发送给所选模型；它不是加密存储，也不应被视为对模型服务保密。
- 两种模式（分析师 / 哲学家）各有独立的提示词与视觉（暖黄 / 克莱因蓝），由 CSS 变量驱动，模式选择保存在浏览器本地。
- 代理安全检查：`node --test test/api.test.js`。
