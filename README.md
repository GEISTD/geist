# Geist 使用指南

**从零开始，只要会打开网页就能用。** 不需要懂 AI，不需要懂代码。

---

## 一、Geist 是什么？

Geist 是一个会陪你聊天的 AI，风格像一个**温和、会倾听的心理咨询师**。

它和普通 AI 最大的不同：**它不急着给你答案，它先听你说。** 它会像真人一样问你问题、接住你的情绪，帮你慢慢想清楚自己的事。

> 它的理念写在开场里：
> *先听你说。这里不急。*

【重要提醒】它是 AI，不是医生。它能陪伴、能倾听，但不能替代真正的心理咨询或医院。如果你处于危险或紧急的情绪中，请直接拨打 **全国心理援助热线 12356**。

## 二、最快上手：30 秒开始聊天

### 方式 A：拿到网站文件（最常见）

1. 拿到一个叫 `Geist.html` 的文件（作者发给你，或者微信传给你）。
2. **双击它**，会自动用浏览器打开。
3. 你会看到一张海报一样的欢迎页，大字写着「先听你说。」。右上角可以切换 Geist 的两种模式：
   - **分析师**：暖黄色，像一位温和、会倾听的心理咨询师（开场是歌德《浮士德》的名句，页脚有尼采「骆驼·狮子·小孩」三个小记号）；
   - **哲学家**：克莱因蓝，像一位陪你深夜想问题的人，主题是「上帝已死」（页角有一枚淡淡的头盖骨）。
4. **鼠标在页面任意位置点一下**，等两三秒，Geist 会先开口问你第一个问题。
5. 在最底下的输入框里打字，按 **回车键**（Enter）发送，像聊微信一样。

### 方式 B：点开公开网址（最简单）

直接打开 **geistd.github.io/geist**（推荐，手机上收藏一下就行），其余步骤和上面第 3 步开始完全一样。

> 小知识：这个网址是托管在 [GitHub Pages](https://pages.github.com) 上的——GitHub 免费把仓库里的网页文件发布成网站，点开就能用。公开网址没有后台，聊天走公共免费通道（偶尔慢）；想接上"钥匙"就在网页右上角「偏好」里填自己的 key。

### 小提示

- 回复可能需要等几秒到几十秒，看到三个小点跳动就是它正在"想"，耐心等一下。
- 没话说很正常，你可以发「不知道说什么」，它也会接得住。
- 聊天的内容**只保存在你自己的浏览器里**，不会上传。

## 三、进阶（可选）：让它更"聪明"一点

默认情况下 Geist 也能聊，但用的是公共免费通道，偶尔会慢、会笨。

花 5 分钟接一个**免费的"钥匙"**，它会明显更流畅、更会说话。

### 大白话解释

"钥匙"叫 **API Key**（念作 A-P-I key）。你可以把它理解成：给 Geist 装上一个更好的大脑的门禁卡。这张卡是**免费的**，不需要花钱。

### 步骤（跟着做就行）

1. 用浏览器打开 [open.bigmodel.cn](https://open.bigmodel.cn)（智谱，一家国内的 AI 公司）。
2. 点右上角「注册 / 登录」，用**手机号 + 短信验证码**注册（可能还要身份证实名，按页面提示来就可以，都免费）。
3. 注册登录进去后，找到左侧的 **「API Keys」**，点「创建」，会生成一串字母数字混合的密钥，**点复制**。
4. 回到 Geist 网页。第一次打开聊天后，它会弹出一张卡片，标题是 **「接一个你常用的模型」**：
   - 下拉框选 **「智谱 GLM-4-Flash（免费）」**（地址和模型名会自动填好）；
   - 把刚才复制的密钥粘贴进 **「API Key」** 那一栏；
   - 点 **「保存并开始」**。
5. 搞定。以后它都会自动用这个更好的大脑，不用再管。

> 没看到卡片？点网页右上角的 **「偏好」**，里面填同样的三样东西，点「保存」。

### 想换其他公司的模型？

卡片的下拉框里还有 DeepSeek、OpenAI、Claude、通义千问等选项。选哪个就填哪家的密钥（各家的获取方式类似：注册 → 创建 API Key → 复制）。国产的（智谱、DeepSeek、通义）通常最省事、国内就能直连。

## 四、分享给朋友（站长专用，普通使用者可跳过）

这一节需要一点点电脑知识，普通人**不用看**。

1. 下载安装 [Node.js](https://nodejs.org/)（一路点"下一步"即可）。
2. 在 `geist` 文件夹里新建一个 `key.txt`，把智谱密钥粘贴进去，保存。
3. 打开终端（PowerShell），进入 `geist` 文件夹，运行：

   ```powershell
   node server.js
   ```

4. 看到 `本机访问：http://localhost:8788` 就成功了。同一个 WiFi 的朋友访问 `http://你的电脑IP:8788`（用 `ipconfig` 查 IPv4 地址）。
5. 朋友在外网时，可用 cpolar 一类的免费内网穿透工具得到公网地址。

密钥只存在于你的电脑上，朋友只能使用、无法看到。

> 想让朋友**在国内不用 VPN** 也能稳定访问公开网址？看下面第五节，用腾讯云开发（CloudBase）架一个国内版本，和 Vercel 海外版并存。

## 五、架一个「国内免 VPN」的公开网址（CloudBase 部署）

### 这是给谁看的

给站长（你）。目的是做一个**放在国内**的公开网址：不用 VPN、不用备案、不用自己买服务器，点开就能聊，聊天走你自己的智谱密钥。

部署完成后会有两个版本：

| 版本 | 地址 | 适合谁 |
| --- | --- | --- |
| 海外版（Vercel） | geist-pied.vercel.app | 在国外/能上外网的人 |
| **国内直连版（CloudBase）** | 形如 `xxx.tcloudbaseapp.com` | **在国内、不想折腾 VPN 的人** |

两版代码同一套，只是后端线路不同。

### 原理（一句话）

腾讯云开发是腾讯家的"网站+后台"托管服务：**静态托管**放网页文件（国内直连），**云函数**当后台帮你向智谱转发聊天请求。免费额度够个人学习用。

### 准备

1. 访问 [cloud.tencent.com](https://cloud.tencent.com)，用微信扫码注册/登录（个人实名即可）。
2. 打开产品 **「云开发 CloudBase」**（控制台里搜"云开发"），按提示开通（按量计费，无最低消费）。

### 第一步：创建环境

1. 在云开发控制台点 **「新建环境」**，随便取个名（比如 `geist`），地域选离你近的。
2. 创建完成后，在环境卡片上找到一串 **「环境ID」**（类似 `geist-3g2xxxxxxx`），**记下来**，后面要用两次。

### 第二步：创建两个云函数

在控制台左侧选 **「云函数」**，点 **「新建云函数」**，一共建两个：

**① 函数名 `health`**（健康检查，前端靠它探测线路）

- 运行环境选 **Node.js 16+**；
- 直接把仓库里 `cloudbase/health/index.js` 的**全部内容**粘进在线编辑器的 `index.js`，点保存。

**② 函数名 `chat`**（真正的转发员）

- 运行环境同上，粘贴 `cloudbase/chat/index.js` 的全部内容；
- **超时时间改成 60 秒**（智谱回复有时要十几秒）；
- 保存后，在这个函数的 **「编辑 → 环境变量」** 里新增一个变量：
  - 变量名：`GEIST_API_KEY`
  - 变量值：你的智谱密钥（就是第三节那串字母数字）

> 密钥只存在腾讯云的函数配置里，访客、GitHub 仓库都看不到。

### 第三步：开通 HTTP 访问服务

云开发控制台左侧找 **「HTTP 访问服务」**（如果找不到，去 chat 函数的 **「触发管理」** 里建**「API 网关触发」**，用网关给的地址代替下面说的域名，原理一样）。

- 新建两条路径，都绑定到你的环境：
  - 路径 `/health` → 函数 `health`
  - 路径 `/chat` → 函数 `chat`
- 记下默认访问域名，形如 `https://<环境ID>.service.tcloudbase.com`。

**验收**：用浏览器直接打开 `https://<环境ID>.service.tcloudbase.com/health`，能看到 `{"ok":true,...}` 就说明云函数通了（如果没配密钥，`keyConfigured` 是 false，不影响）。

### 第四步：上传网页

1. 控制台左侧选 **「静态网站托管」**（第一次用需要点开通，选你刚建的环境）。
2. 把仓库里的 `Geist.html` **上传**到根目录（覆盖默认的 index.html 没关系，也可以把旧 index.html 删掉）。
3. 记下静态站点的默认域名（形如 `xxx-xxxx.tcloudbaseapp.com`）。

### 第五步：把「环境ID」填回网页文件（重要）

网页需要知道自己该走哪条国内线路，所以要改一行再传一次：

1. 打开 `Geist.html`，搜索 `CB_ENV_ID`（在约 540 行），找到这行：

   ```js
   const CB_ENV_ID = '';
   ```

2. 把环境ID填进引号里：

   ```js
   const CB_ENV_ID = 'geist-3g2xxxxxxx';  // 换成你自己的
   ```

3. 保存，**重新上传覆盖**静态托管里的文件。刷新网页，就能聊了。

> 如果第三步你用的是 API 网关触发的地址（域名像 `service-xxx.gz.apigw.tencentcs.com`），就把 `Geist.html` 里 `CB_FX_BASE` 那行改成 `const CB_FX_BASE = 'https://service-xxx.gz.apigw.tencentcs.com/release';`（网关给你的完整前缀，不要带 `/chat`）。前端会自动识别 `tcloudbaseapp.com` 域名并切换线路。

### 不用的时候

按量计费的环境在控制台可以**直接删除**，不产生费用。免费额度内个人使用通常不花钱；具体额度以腾讯云控制台页面为准。

## 六、常见问题（FAQ）

**Q：它怎么那么久不回话？**
它在"想"。免费通道偶尔慢，等 1 分钟；接了三、里的免费钥匙会快很多。

**Q：我们的聊天会被别人看到吗？**
不会。所有对话只存在你自己的浏览器（或你的电脑）里，不经过第三方平台保存。但换设备/清空浏览器数据后记录会消失，这是正常的。

**Q：它到底是人还是机器人？**
是 AI。它有时真的很像真人，但它是程序，不是真人。

**Q：怎么切换分析师和哲学家？**
右上角有两个小按钮「分析师」「哲学家」，点哪个就换哪个（欢迎页和聊天页都能切）。两种模式的聊天记录各自保存，互不干扰，切换也会记住。哲学家模式下如果聊到生死、意义这类话题，它会陪你想得更深。

**Q：克莱因蓝为什么要配一只头盖骨？**
Geist 在德语里是"精神、鬼魂"的意思。头盖骨是它的记号——死亡气质的克莱因蓝里，藏着 Geist 的幽灵。觉得吓人的话，切到黄色的分析师模式就好。

**Q：我心情真的很差，它能救我吗？**
它能陪你、听你说，但**不能替代医生**。强烈建议联系信任的人，或拨打 **12356**（全国心理援助热线，免费）或 **400-161-9995**（希望24热线）。

**Q：换了一台电脑，怎么做？**
把 `Geist.html` 文件拷过去（或重新打开网址）就行。想接"钥匙"就在那台电脑上重新填一次。

## 七、技术说明（给开发者）

- 单文件前端：`Geist.html`，无框架、无依赖，双击即用。
- 模型线路优先级：个人 key（「偏好」配置）→ 部署站点代理线路（`server.js` 本机 / `api/` Vercel / `cloudbase/` 腾讯云，按部署位置自动识别）→ 免密钥线路（Pollinations）。`Geist.html` 里 `CB_ENV_ID` 留空时 CloudBase 检测完全不生效，行为零变化。
- 人格提示词以 Rogers–Gloria、焦点解决（SFBT）、动机式访谈（MI）、CBT 首访、精神分析案例（弗洛伊德的朵拉/鼠人、Sherby 动力学对话）及中文咨询逐字稿等真实实录为基准校准；哲学家一面的语气，另以尼采、维特根斯坦、萨特、加缪、庄子等人的访谈、文字与著作姿态为基准。每轮回复附带仅供模型自用的 `<internal>` 内部个案笔记，前端解析时剥离，永不展示。
- 两种模式（分析师 / 哲学家）各有独立的提示词与视觉（暖黄 / 克莱因蓝），由 CSS 变量驱动，模式选择保存在浏览器本地。
- 任意 OpenAI 兼容接口均可接入（智谱 / DeepSeek / OpenAI / Claude 兼容层 / 通义等）。
